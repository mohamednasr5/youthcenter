# مركز شباب الأحمدية — المنصة الرسمية

منصة ويب احترافية لمركز شباب الأحمدية (المنزلة - الدقهلية - مصر). موقع ثابت (Static) متعدد الصفحات، مع لوحة تحكم لتعديل كل المحتوى، وتطبيق PWA يعمل دون اتصال.

> برمجة وتطوير: **المهندس محمد حماد**

---

## ✨ المميزات

- 🎨 تصميم احترافي داكن مع تأثيرات **3D** وأنيميشن مميز (parallax، tilt، عدّادات متحركة، reveal عند التمرير).
- 📰 **شريط أخبار**: على الكمبيوتر شريط متحرك عادي، وعلى الهواتف **برق إخباري** — الخبر يصعد من تحت، يقف في النص لحظات، يختفي ويأتي غيره (كليك للإيقاف المؤقت).
- 💰 **إحصائيات مالية** تُدخل يدوياً من لوحة التحكم وتظهر للزوار كما هي.
- 📡 **قسم آخر منشور على فيسبوك**: تحت الإحصائيات المالية مباشرة — يُجلب آخر منشور على صفحة المركز **facebook.com/Markz.shabab.elahmadya** تلقائياً (نص المنشور + الصورة + التاريخ + رابط المنشور).
- 🔗 وسائل التواصل: **صفحة فيسبوك رسمية فقط**.
- 👥 قسم **مجلس الإدارة** بصور الأعضاء.
- 🏟️ روابط لأكاديمية كرة القدم، أكاديمية الكاراتيه، ونظام حجز الملعب الخماسي.
- 📝 **مقالات** بصفحة خاصة لكل مقال (`article.html?id=`).
- 📅 **نشاطات قادمة** (رياضي / ديني / تثقيفي / ترفيهي).
- 💰 **إحصائيات مالية** شهرية في جانب ثابت.
- 🛠️ **لوحة تحكم** (`admin.html`) لتعديل أي شيء في الواجهة وحفظه.
- 📱 **PWA**: قابل للتثبيت كتطبيق ويعمل دون اتصال (Service Worker + Manifest).

## 📡 قسم «آخر منشورات فيسبوك» (تحت الإحصائيات المالية)

الموقع يعرض آخر منشور على صفحة المركز **facebook.com/Markz.shabab.elahmadya** في قسم مستقل تحت بطاقة الإحصائيات المالية مباشرة: نص المنشور، الصورة، التاريخ («منذ ساعتين» مثلاً)، وزر «عرض المنشور على فيسبوك».

> ملاحظة: **الإحصائيات المالية لا علاقة لها بهذا القسم** — تُدخل يدوياً من لوحة التحكم وتظهر للزوار كما هي.

**1) جلب تلقائي دائم لكل الزوار (GitHub Action):**

1. من فيسبوك: أنشئ تطبيقاً على developers.facebook.com ثم استخرج **Page Access Token طويل الأمد** للصفحة (صلاحية قراءة المنشورات فقط).
2. في مستودع GitHub: **Settings → Secrets and variables → Actions → New repository secret** وأضف:
   - `FB_PAGE_ID` = `Markz.shabab.elahmadya` (أو الرقم التعريفي للصفحة)
   - `FB_PAGE_TOKEN` = التوكن
3. الـ workflow `.github/workflows/update-fb-post.yml` يعمل يومياً 07:00 ص بتوقيت القاهرة، يجلب آخر منشور ويكتب `fb-post.json` ويرفعه — فيتحدّث الموقع لكل الزوار تلقائياً بدون كشف التوكن.

**2) جلب فوري من المتصفح (اختياري):** أدخل «معرف الصفحة + التوكن» من لوحة التحكم (قسم إعدادات الموقع → روابط التواصل الاجتماعي) ثم اضغط «اختبار جلب آخر منشور من فيسبوك».

ترتيب الأولوية: كاش محلي يُعرض فوراً ← Graph API (إن وُجد التوكن) ← `fb-post.json` ← بطاقة «متابعة صفحة المركز» برابط الصفحة.

## 🛠️ لوحة التحكم

1. افتح `admin.html` في المتصفح.
2. كلمة المرور الافتراضية: **`ahmadiah2026`** (غيّرها من قسم «الإعدادات»).
3. عدّل أي قسم: الإعدادات، الأخبار، الإعلان، مجلس الإدارة، المقالات، النشاطات، الإحصائيات، الأكاديميات.
4. اضغط **«حفظ التغييرات»** أسفل الصفحة.
5. التغييرات تُحفظ في متصفحك (localStorage) وتظهر على الموقع بعد التحديث.

### نسخ احتياطي
- من قسم «نسخ احتياطي»: **تصدير** كل البيانات كملف JSON، أو **استيراد** نسخة سابقة.
- زر **«استعادة الافتراضي»** يعيد كل المحتوى لحالته الأصلية.

> ⚠️ ملاحظة: لأن البيانات تُحفظ في localStorage الخاص بكل متصفح، فإن الزائر العادي يرى المحتوى الافتراضي. لتغيير المحتوى الافتراضي لكل الزوار، عدّل ملف `data.js` مباشرة.

## 🚀 التشغيل محلياً

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً بسيطاً:

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

> الـ Service Worker وPWA يتطلبان تشغيل الموقع عبر خادم (http) وليس فتح الملف مباشرة (file://).

## ☁️ النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub (مثلاً `ahmadiah-youth-center`).
2. ارفع محتويات هذا المشروع:
   ```bash
   git init
   git add .
   git commit -m "النسخة الأولى لمركز شباب الأحمدية"
   git branch -M main
   git remote add origin https://github.com/<USER>/ahmadiah-youth-center.git
   git push -u origin main
   ```
3. من إعدادات المستودع: **Settings → Pages → Source: Deploy from branch → main /(root)**.
4. انتظر دقائق، ثم افتح الرابط: `https://<USER>.github.io/ahmadiah-youth-center/`.

أو استخدم الـ workflow الجاهز في `.github/workflows/deploy.yml` (يُفعّل تلقائياً عند الرفع وينشر الموقع عبر GitHub Actions).
